요청한 책 링크 — 제목을 누르면 서점 페이지로

홈의 회차 구매 요청 표에서 책 제목 옆에 작은 링크 표시를 붙이고, 제목을 누르면 요청할 때 넣은 서점 상품 페이지(yes24 · 교보문고)가 새 탭으로 열려요. 다른 사람이 어떤 책을 골랐는지 서점에서 다시 찾아보지 않아도 돼요. 표의 칸·폭·순서는 그대로예요.

바뀌는 것

  • 데스크톱 표의 책 제목 · 글자 뒤에 바깥 화살표 ↗, 제목 전체가 링크
  • 모바일 목록의 책 제목 · 같은 모양. 손가락으로 제목을 누르면 열려요
  • 전체 · 내 요청 둘 다, 지난 회차를 골라도 똑같이
  • 안 바뀌는 것 · 요청자 · 서점 · 금액 · 진행 칸, 시트용 복사, 구매 요청 화면

  • 어디로 · 요청 때 저장된 url 그대로. 이미 있는 값이라 새로 저장할 것 없음
  • 어떻게 · 새 탭 (target="_blank" rel="noopener"). 주문·배송 화면의 상품 링크와 같은 방식
  • 마우스를 올리면 · 제목에 밑줄, 화살표가 빨갛게. 주소는 브라우저 말풍선으로 (yes24.com/product/goods/…)
