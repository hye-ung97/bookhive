로그인 · B 시간표로 맞추기

지금 로그인 화면만 종이색 바탕, 얇은 베이지 선, 명조 제목, 둥근 모서리를 써서 앱 안쪽과 말투가 달라요. 앱 안쪽과 같은 B 시간표 규칙으로 맞춘 세 가지를 이전 화면 아래에 나란히 그렸어요. 문구는 지금 것을 그대로 쓰고 자리만 옮겼어요. 새로 생긴 문구는 각 시안 머리에 적어 두었어요.

세 시안 모두 같은 것

  • 바탕·잉크 흰 바탕 --bg, 검은 잉크 --ink, 보조 글자 --ink2. 로그인 전용 --lg-* 토큰은 없애요.
  • 글꼴 Pretendard 하나. 큰 문장은 홈 머리와 같은 .t-title (44px, 모바일 30px).
  • 줄·모서리 구역은 2px 검은 줄, 줄 사이는 1px 회색 줄. 모서리는 모두 직각.
  • 빨강 미등록 계정 안내에만. 앱의 .note.note-danger와 같은 모양 (왼쪽 4px).
  • 푸터 앱 .foot과 같은 한 줄. 로그인 전 화면이라 메일은 빼고 Design by Doan · 개인정보처리방침만.
  • 예외 Google 버튼은 브랜드 가이드 색·모양 그대로 둬요 (지금 코드와 같음).

세 시안 — 무엇이 다른가

  • A · 배치 그대로 — 지금처럼 왼쪽 큰 문장, 오른쪽 회차 순서. 겉모습만 B로 바꿔요. 코드는 CSS 위주라 셋 중 가장 적게 바뀌어요.
  • B · 한 장 — 개인정보처리방침·404와 같은 가운데 720px 틀(.solo). 앱 밖 화면 셋이 한 모양이 되고, 회차 순서는 가로 세 칸이 돼요.
  • C · 앱 틀 — 앱의 왼쪽 목차 자리에 로고·회차 순서, 오른쪽 본문에 홈과 같은 머리·구역 머리. 로그인 전후로 화면 뼈대가 같아요. 모바일은 하단 탭 자리에 Google 버튼.

정한 것

  • 시안 A · 배치 그대로.
  • 명조 글꼴 쓰는 곳이 없어져서 layout.tsx의 나눔명조 로딩과 --font-serif를 지웠어요.
  • Design by Doan 로그인 푸터에도 넣었어요. 메일 줄만 빼요 (<SiteFooter contact={false} />).

그리지 않은 상태

  • 일반 로그인 오류 미등록 안내와 같은 자리·같은 모양에 "로그인하지 못했어요. 다시 시도해 주세요." 한 줄.
  • 개발용 이메일 로그인 로컬에서만 보여요. 버튼 아래 1px 줄 뒤에 앱 .input·.btn으로.
  • 모바일 미등록·다크 모드·hover·focus 앱 공통 토큰과 규칙을 그대로 따라요.

A로 정함 A는 src/app/login/page.tsx, globals.css 로그인 부분, 공용 푸터 src/components/site-footer.tsx에 들어갔어요. 나눔명조 로딩도 지웠어요. 맨 위 "이전"은 바꾸기 전 코드, B·C는 처음 시안 그대로 남겨 둔 것이고 코드에 없어요.
