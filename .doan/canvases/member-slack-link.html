멤버 화면에서 Slack 연결하기

멤버 표의 Slack 칸을 누르면 연결 창이 떠요. Slack 멤버 ID(U로 시작)를 넣으면 저장할 때 Slack에서 확인하고, 표에 Slack 이름을 같이 보여 줘요. 멤버 화면과 설정 화면은 같은 말(연결 · 미연결)을 써요.

왜 어긋나 보였나

  • 두 화면은 같은 값 members.slack_user_id를 봐요. 값이 비어 있을 때 멤버 화면은 회색 "첫 알림 때 연결", 설정 화면은 "Slack 미연결"이라고 써서 다른 상태처럼 보였어요.
  • "첫 알림 때 연결"은 알림을 보낼 때 봇이 Google 이메일로 Slack 계정을 찾는 자동 연결이에요. Slack 가입 이메일이 다르거나 봇이 설정 전(기록만 남김)이면 계속 비어 있어요.
  • 설정 화면 맨 위 "Slack이 아직 연결되지 않아…"는 봇 토큰·채널 설정 얘기라 멤버 연결과 다른 문제예요. 문구를 나눠요(03).

정한 것

  • 연결은 Slack 멤버 ID 직접 입력이 기본. [이메일로 찾기]는 같은 창의 보조 버튼 (지금 자동 연결과 같은 방법을 눌러서 바로 해 보는 것).
  • 저장할 때 Slack에서 확인해요. 없는 ID·비활성 계정·봇은 막고, 찾으면 Slack 이름을 받아 표에 같이 보여 줘서 엉뚱한 사람인지 눈으로 확인해요.
  • 같은 ID는 두 멤버에 못 넣어요.
  • 연결 끊기는 넣지 않았어요. 비워 두면 다음 알림 때 이메일로 다시 찾아 붙어서 의미가 없어요. 다른 ID로 바꾸기만 돼요.
  • 봇이 설정 전이면 형식만 보고 저장하고 표에 "확인 전"으로 둬요. 봇을 설정한 뒤 첫 알림 때 확인해요.
  • 창은 지금 [수정]·[탈퇴 처리]와 같은 dialog.dlg. 저장되면 닫히고 표의 그 줄이 바뀌어요.

코드에 없는 것 코드에 없음

  • 화면: Slack 칸 버튼·[연결하기], 연결 창(새 컴포넌트), 모바일 줄의 Slack 글자 버튼, 표 위 미연결 안내 줄, 멤버 추가 폼의 Slack 멤버 ID 칸
  • 문구: 이 캔버스의 Slack 관련 문구 전부 (미연결·연결하기·확인 전, 연결 창 안내·오류 문구, 설정의 봇 미설정 문구)
  • 서버: ID 저장 액션 + Slack users.info 확인 (스코프 users:read는 이미 있음), 프로필 링크에서 ID 골라내기, 같은 ID 중복 막기(unique)
  • DB: Slack 이름 칸 (예: members.slack_name). 이름이 비어 있고 ID만 있으면 "확인 전"
  • 설정: 미연결 칩 표시, 미리보기에서 멘션 안 되는 이름 표시, 멤버 화면으로 가는 링크
